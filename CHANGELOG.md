# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-11-18

First release of laravel-quebec-vendors: a register of the vendors you communicate personal information to under Quebec Law 25, with the written mandate contract checklist for service providers (s. 18.3), the privacy impact assessment before communicating outside Quebec (s. 17), risk-based reviews and termination. Part of the Quebec Law 25 suite for Laravel.
